실제 식물 획득은 오늘의 할 일을 모두 완료했을 때 하루 한 번만 발생해요.

Plantory 사용 방법

1. HOME은 오늘 할 일과 성장하는 식물을 보여줘요. 할 일은 개수 제한 없이 등록할 수 있어요.

2. DAY에서는 날짜별 할 일·약속을 색상 카드로 확인해요.

3. MONTH에서는 한 달의 일정을 확인해요. 좌우로 밀면 DAY → HOME → MONTH가 원형으로 연결되고, 월 달력 안에서 위·아래로 밀면 달을 바꿀 수 있어요. 화살표로도 이동할 수 있어요.

4. 식물은 오늘 등록한 할 일을 모두 완료하면 꽃이 피고, 세 종류 중 하나를 하루에 한 번 획득해요. 약속은 식물 성장에 포함되지 않아요.

5. 색상은 기록마다 선택할 수 있고 기본색으로 저장할 수 있어요. 계절 배경과 별개로 유지돼요.

6. 백업은 설정에서 JSON 파일로 내보내거나 불러올 수 있어요.

제한: WebGL 3D를 사용해 식물을 회전하고 성장 단계를 볼 수 있어요. 일부 브라우저에서 WebGL이 차단되면 2D 대체 그림이 표시돼요. 닫힌 앱에 보내는 푸시 알림과 여러 기기 자동 동기화도 아직 제공하지 않아요.
