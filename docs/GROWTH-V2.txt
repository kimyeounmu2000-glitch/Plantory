성장 시스템 v2
- 기존 비율 계산 대신 완료 개수와 절반 기준을 함께 사용합니다.
- growth[날짜]에 최대 단계를 저장합니다. awards와 기존 저장 키는 유지합니다.
- commitTasks: 할 일 변경, 성장, 보상을 한 번에 저장하고 실패 시 전체 상태를 되돌립니다.
- normalizeGrowth: 이전 백업의 보상 날짜는 개화 단계로 복원합니다.
- animateGrowth: 단계당 450ms, 모션 감소 설정과 화면 전환 취소 지원.
- growth-v2-reference.js는 유지보수용 참고 소스입니다. 실행본 HTML에도 동일 코드가 포함되어 있습니다.
검증: 0/1/2/3/5/10개 성장, 체크 취소, 최대 단계 유지, 새로고침, 삭제 후 보상과 전체 삭제, 저장 실패, 미리보기 데이터 격리, 6종과 스와이프.
미검증: 실제 휴대폰, 자정 실시간 경과, 백업 파일 다운로드/복원 전체 UI, 성장 연출의 모든 프레임 육안 확인.
