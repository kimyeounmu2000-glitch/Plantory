# 저장 안내 A/B — 인간 검증 준비

상태: 참여자 0명, 실제 인간 조사 전부 미실시. AI 결과로 채우지 않는다. 제품 반영 미승인.

## 현재 안내 평가
설정의 '현재 기기' 표현과 데이터 삭제/기기 변경 전 백업 안내, 도움말의 자동 동기화 미지원 설명은 대체로 구현과 일치한다. 다만 기기보다 '현재 브라우저의 이 사이트'가 정확하다. 브라우저/프로필/origin이 바뀌면 저장 공간도 다르다. file URL별 동작은 브라우저마다 달라 실기기 확인이 필요하다. 복원 대체 확인과 v2 원본 보존/구버전 비동기화 안내는 실제 코드에 있다. 동기화로 오해한다는 주장은 아직 가설이다.

A는 핵심 설명을 한 번에 읽기 쉽지만 이전 중단의 세부 맥락은 적다. B는 상황별 설명이 자세하지만 읽기·펼치기 부담이 늘어난다. 목업 버튼은 작동하지 않는다. 실제 H3 수행은 격리된 앱에서 한다. 목업은 적용 효과가 검증된 디자인이 아니다.

## 대상 및 동의
성인 5명, 일정 앱 경험·브라우저 숙련도·키보드 사용 여부를 골고루 기록한다. 통계적 대표 표본이 아니다. 참가자는 별도 합성 데이터 데모만 사용하고 실제 이름/일정/계정을 입력하지 않는다. 언제든 중단 가능하고 보상 여부와 무관하다. 녹화·인용·관찰 동의를 각각 받는다. 동의 없는 녹화/인용 금지. P01~P05만 사용하고 연락처와 관찰 파일을 분리한다. 보관 담당자·접근자·보관 위치·삭제일은 모집 전에 사용자가 확정한다. 제안 보관 기간은 검토 종료 후 30일 이내이며 자동 적용한 정책이 아니다.

## 진행자 문안
“앱과 설명을 검사하며 참가자를 평가하지 않습니다. 이해한 내용을 편하게 말씀해 주세요. 어려우면 도움을 요청하거나 멈춰도 됩니다. 화면에는 가짜 기록만 있습니다.”
정답을 알려주거나 '백업 버튼은 설정에 있어요' 같은 힌트를 먼저 제공하지 않는다. 도움 요청 시 요청 시각과 제공한 내용을 기록한다. 과제 종료 후 동일한 설명을 제공한다.

## 과제 및 판정
H1 기록이 어디에 저장되는지 설명: 현재 브라우저/사이트 범위가 핵심. 서버 계정에 자동 보관된다고 답하면 오해 기록.
H2 다른 기기에서 자동으로 보이는지 설명: 자동 동기화 없음.
H3 도움 없이 JSON 내보내기 찾기: 시작~기능 발견 시간, 성공/도움 성공/실패/포기. 실제 데모 파일 다운로드만 허용.
H4 사이트 데이터 삭제 후 상황 설명: 기록 소실 가능, 백업 없는 복구 보장 없음. 실제 삭제는 하지 않음.
H5 기기 변경 전 보존 절차: 기존 환경 백업→파일 보관→새 환경 명시적 복원. 기존 새 기록은 별도 백업.
H6 v2→v3 설명: 사용자 확인 복사, v2 보존, 구버전 후속 수정 자동 동기화 없음. 실제 이전 강요하지 않음.

A→B 3명, B→A 2명으로 순서를 교차한다. 처음 본 안의 무도움 결과와 두 번째 안의 학습 영향을 분리한다. H3 반복은 다른 합성 데이터 데모로 수행하되 화면 경로 학습 효과는 제거됐다고 주장하지 않는다. 두 안 비교 후 더 쉬운 이유를 자유롭게 질문한다. 디자인 효과나 인과관계로 일반화하지 않는다.

잠정 기준: 5명 중 최소4명이 H1/H2 정답 및 H3 무도움 발견. 이는 내부 검토 기준이지 업계 표준/통계적 유의성 아님. 오류 가정·혼동 용어·도움 요청·과도한 불안·잘못된 복구 기대도 별도 기록한다.

## 접근성
목업은 한국어 lang, 제목 위계, 기본 details/summary 키보드 조작, 보이는 포커스, 작은 화면 줄바꿈을 사용한다. 화면낭독기 실검증 미실시. 의미 전달을 색상에만 의존하지 않는다. 실제 앱 H3는 이번 키보드 수정 후보를 사용하고 후보 버전/SHA를 기록한다.

## 기록 양식
observations.csv에 익명 ID, 제시 순서, 안, H번호, 무도움/도움/실패/포기, 경과초, 답변 요약, 잘못된 가정, 도움, 인용동의, 분석자 해석을 분리한다. 빈 값은 미실시이지 실패나 0초가 아니다.

결과 템플릿: 참여자 [미실시], H1정답 [미실시], H2정답 [미실시], H3무도움 [미실시], 발견시간 [미실시], H4~H6오해 [미실시], A/B차이 [미실시], 선호와 행동의 불일치 [미실시], 다음 수정 승인안 [보류].

실기기 전: 실제 기록을 사용한다면 별도 JSON 파일 존재/구조/복원 가능성을 먼저 확인하고 모든 구버전 탭을 닫는다. 이번 검증은 합성 데이터만 사용한다. iPhone Safari/Android Chrome에서 터치·가상키보드·safe area·다운로드/복원·다중탭·재시작을 각각 기록한다. 브라우저 사이트 데이터를 지우는 시험은 실사용 프로필에서 하지 않는다.
