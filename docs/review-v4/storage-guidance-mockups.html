기록을 안전하게 옮기기

검토용 목업 — 앱 미적용. 버튼은 예시이며 파일이나 저장 데이터를 읽거나 변경하지 않습니다.

A · 짧은 안내

기록은 지금 사용하는 브라우저의 이 사이트 저장 공간에 남아요. 다른 기기나 브라우저로 자동 동기화되지 않아요.

설정 → ‘JSON 백업 내려받기’에서 기록 파일을 보관해 주세요. 기기를 바꾸거나 사이트 데이터를 지우기 전에 백업하면 새 환경에서 복원할 수 있어요.

백업 없이 지워진 기록은 복구하지 못할 수 있어요. 복원은 현재 기록을 바꾸므로 현재 기록도 먼저 백업해 주세요.

B · 상황별 안내

기록은 현재 브라우저의 이 사이트에 저장되며, 기기 간 자동 동기화는 제공하지 않아요.

기기나 브라우저를 바꿀 때

기존 환경의 설정에서 JSON 백업을 내려받아 따로 보관하세요. 새 환경에서 파일을 선택하고 교체 내용을 확인해 복원하세요. 양쪽에서 편집한 기록은 자동으로 합쳐지지 않아요.

사이트 데이터를 지우기 전

사이트 데이터를 지우면 앱 기록도 사라질 수 있어요. 먼저 백업 파일을 내려받으세요. 백업이 없는 삭제 기록의 복구는 보장할 수 없어요.

이전 버전 기록을 옮길 때

구버전 탭을 닫고 원본을 백업한 뒤 ‘기록 확인 후 이전’을 선택하세요. v2 원본은 남기고 v3 저장 공간으로 복사해요. 구버전에서 나중에 바꾼 내용은 새 버전에 자동 반영되지 않아요. 중단 안내가 나오면 원본을 지우지 말고 안내에 따라 확인해 주세요.

JSON 백업을 복원할 때

복원은 현재 기록과 합치는 기능이 아니라 백업의 기록으로 교체하는 기능이에요. 현재 기록을 먼저 내보내고 파일과 교체 내용을 확인하세요. 손상되거나 지원하지 않는 파일은 적용되지 않아요.
