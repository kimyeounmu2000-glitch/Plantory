## 2026-11-10

- 확인 대상은 11월 5일 작업의 로컬 `outputs/seed-garden` 사본이다. Git 저장소 메타데이터가 없으며 최신 브랜치·배포본과의 일치는 확인하지 않았다.
- `index.html`과 `style.css`가 화면을 구성하고, `app.js`가 UI와 `localStorage`의 `soso-garden-v1` 데이터를 관리한다. `model.js`는 날짜·보상 로직, `plant.js`는 로컬 Three.js r170과 식물 렌더링, `plant-fallback.js`는 대체 렌더링, `sw.js`와 매니페스트는 PWA를 담당한다.
- Node v26.13.0에서 `node --test tests.mjs` 6개 통과. `npm start`는 로컬 Node 서버를 실행한다. npm 의존성과 node_modules는 없으며 프로젝트 전용 Skill은 찾지 못했다. Codex에 제공된 기존 GitHub·웹·브라우저 도구로 조사와 일회성 점검이 가능하다.
- README상 iPhone 설치·터치·오프라인 실기기 확인이 남았다. 내일 일정의 조기 체크는 허용되고 보상은 날짜가 된 뒤 지급된다. 월간·연간 3D 정원, 백업·기기 간 동기화는 README에서 미구현으로 안내한다. 이 기록은 실기기나 배포 검증을 포함하지 않는다.

## 2026-11-12 데이터 보존 수정과 첫 사용·재방문 검토

기준: main e469574, 작업 브랜치 fix/storage-preservation. 사용자 요청으로 중단된 저장 보호 수정을 마무리했다. UX는 읽기 전용 분석이며 화면·모델·성장/보상 규칙과 저장 형식은 변경하지 않았다.

- 저장 진입점을 Web Locks로 직렬화하고, 처음 읽은 저장값과 현재 값이 다르면 오래된 탭의 저장을 거절한다. 새로고침 후 다시 작업할 수 있다.
- 손상된 JSON과 빈 문자열을 새 사용자로 취급하지 않는다. 읽기 실패 시 원본 저장값을 보존하고 쓰기를 중단한다. 자동 복구나 병합은 하지 않는다.
- 한계: Web Locks가 없는 환경은 저장을 차단한다. 이전 배포본 탭은 같은 잠금에 참여하지 않는다. 손상 상태에서 앱 내 복원도 차단되므로 원본을 별도로 보존한 복구 절차가 추가로 필요하다. 그 상태의 내보내기를 원본 복구본으로 간주하면 안 된다.
- 격리된 가짜 데이터 검사: 동시/오래된 탭 저장, 완료 롤백, 삭제·색상·복원 충돌, 새로고침 후 저장, 손상/빈 저장값 보존, 이전 키 이관 통과. check-growth, check-backup, check-plant-gesture, check-integrated 및 legacy 6개 통과. 6종×4단계 실행·모바일 렌더·페이지 오류 검사 포함. 재생성 HTML SHA-256 일치. 실제 사용자 저장소는 접근·변경하지 않았다.
- 실제 휴대폰, 다른 브라우저, 이전 배포본과 새 버전 혼용, 실제 사용자 이해도·다음 날 재방문율은 미검증이다.
