## 2026-11-13 P0 저장 보호 검토 (main 병합 전)

기준 main e469574. 기존 950598a를 검토하고 fix/p0-storage-review에서 보완했다. 950598a의 변경은 생성 입력/HTML, 저장 회귀 검사, 비동기 저장 완료를 기다리는 성장 검사, 기록 문서이며 두 데이터 손실 문제에 해당한다. 원래 main은 오래된 메모리 전체 저장과 읽기 오류 이후 기본 데이터 저장을 허용했다.

- 기존 persist의 원문 비교 + storageMutation의 Web Locks 조합을 유지했다. 비교와 쓰기 및 롤백까지 같은 origin/키 잠금에서 처리한다. 단순 비교만으로 원자성을 보장한다고 가정하지 않는다.
- 읽기 실패 시 모든 쓰기와 가져오기를 막고 원문을 보존한다. 자동 초기화·새 저장 키·데이터 형식 변경은 없다.
- 추가 보완: exportBackup은 손상 상태에서 빈 JSON을 정상 백업처럼 내보내지 않고 현재 저장 원문을 가공 없이 recovery-original 날짜.txt로 내려받는다. 이는 정상 복원 JSON이 아니다. 저장소 접근 불가 시 백업을 만들지 않는다. 오래된 탭의 정상 백업도 새로고침을 안내한다.
- 잠금 미지원/잠금 오류 시 체크 표시를 다시 렌더링해 저장되지 않은 완료 표시가 남지 않게 했다.

### 안전한 복구 절차
1. 다른 Plantory 탭과 이전 버전 탭을 닫고 해당 주소를 유지한다. 저장소 삭제나 초기화를 하지 않는다.
2. 도움말은 닫기 버튼으로 닫고 설정의 기존 백업 버튼으로 복구용 원문을 개인 파일로 보존한다. 빈 원문도 그대로 보존된다. 읽기 자체가 차단되면 파일 생성이 불가능하므로 브라우저 접근 문제부터 해결한다.
3. 손상 원문은 별도 복사본에서만 분석한다. 유효한 과거 JSON 백업이 있다면 다른 origin/격리 브라우저에서 먼저 복원해 일정·꽃·성장·재실행을 확인한다. 원문 txt를 바로 가져오지 않는다.
4. 실제 저장소 교체는 검증된 복구본과 사용자 명시적 선택이 필요하다. 이번 변경은 손상 origin에서 강제 복원을 제공하지 않으며, 원본을 덮는 자동 복구는 구현하지 않았다.

- 잠금 미지원 테스트 초회 실패는 check()가 완료 체크 유지를 기다렸기 때문이며, 실제 요구는 미저장 체크의 복귀다. click() 후 원문 동일/체크 해제를 검사하도록 수정했다.

11월 12일 경쟁 앱 조사 원문은 이번에 제공되지 않아 해당 결과를 검증했다고 주장하지 않는다. 사용자가 전달한 원칙과 현재 코드에 한정한다.
1. 첫 행동: 기존 첫 안내/목표 추가 버튼을 유지한 현재 화면과, 첫 안내 문구를 목표 하나 등록에 집중한 정적 목업을 비교한다. 새싹이 왜 나타났는지 설명할 수 있는지 확인한다.
2. 보상·정원: 목표 하나 완료 시 바로 꽃을 받는 현행 규칙을 설명하는 목업과 현행 화면을 비교한다. 세 종류라는 문구와 실제 6종의 불일치를 정정 후보로 유지한다. 정원에서 어제 날짜의 성취를 이해하는지 묻되 날짜 연결 기능은 아직 추가하지 않는다.
3. 가독성·재방문: 실제 모바일/키보드로 안내 읽기·버튼 찾기·모달 닫기와 다음 날 기록 보존 이해를 검사한다. 대비·포커스 문제는 별도 승인 대상으로 유지한다.

사용성 검사 제안: 처음 쓰는 참가자 5명 정도의 소규모 탐색 검사에서 현재 화면/목업 제시 순서를 번갈아 배정한다. 지시 없이 첫 목표 등록→완료→꽃→정원 찾기 과제를 수행하게 하고 첫 클릭, 도움 요청, 완료 여부, 자신의 말로 설명한 보상 조건을 기록한다. 다음 날 자발적 재방문과 안내를 받고 재방문한 경우를 구분한다. 같은 작업 반복의 학습 효과를 기록하고, 작은 표본을 전환율 개선 증명으로 사용하지 않는다. 참가자 모집·실험·목업 제작은 미실시이며 UX 앱 코드 변경 없음.
- 최종 check-storage 재실행 통과: 오래된 탭·동시 저장 차단, 새로고침 후 재시도, 완료/삭제/색상/가져오기 충돌, 손상·빈 원문 쓰기 차단 및 다운로드 내용 정확 일치, 잠금 미지원 시 기록/체크 보존, 기존 legacy 이관. 최종 실패 검사 없음. main 병합·push·배포는 수행하지 않았다.
